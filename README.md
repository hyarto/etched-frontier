# 蚀刻防线 Etched Frontier

横屏塔防 PWA:动态造迷宫 × 三段式能量回路(能源核心 → 逻辑调制器 → 终端炮塔)× 肉鸽构筑。

## 特色
- **4 章 × 6 关**(含 4 个机制 Boss),环境词缀、动态抗性、过热、传送门、地形坍缩
- **10 种终端炮塔**:机枪 / 狙击 / 迫击炮 / 激光 / 无人机 + 霰弹塔 / 火焰喷射器 / 特斯拉线圈 / 导弹井 / 磁轨炮,每种 Lv3 后 2 条改造路线
- **∞ 无尽肉鸽模式**:随机地图、无限波次、每 10 波一个 Boss、历史最佳记录
- **每局抽卡增益**:25 张卡牌(普通/稀有/史诗),开局三选一,无尽模式每 4 波再抽;可叠加、可重抽
- **敌人肉鸽**:9 种波次变异(下一波提前预告)+ 6 种精英词条(再生/护盾/疾行/重甲/自爆/孕育)+ 维修无人机
- 以太三选一抽取、指挥官技能、3 个非对称指挥核心、局外实验室、10 级熵增协议、每日种子
- **PWA**:可安装,Service Worker 预缓存整个应用外壳,断网也能完整游玩,存档保存在 localStorage

## 开发
```bash
npm install
npm run dev
npm run build
```

## 部署到 Vercel
直接导入仓库即可(已包含 `vercel.json`:框架 Vite、输出目录 `dist`、SPA 回退、`sw.js`/`manifest` 不缓存、图标长缓存)。
无需任何环境变量。

## PWA / 离线说明
- `public/sw.js`:安装时预缓存 `/` 及页面引用的全部本地资源;外壳缓存失败则安装失败并在下次访问重试。
- 页面导航网络优先(3.5s 超时),离线或弱网回退到缓存外壳;其他静态资源缓存优先 + 后台更新。
- 发布破坏性更新时递增 `sw.js` 中的 `VERSION`,旧缓存会在激活时清理。
- 首次联网打开后,主菜单会显示「离线可玩 ✓」。
